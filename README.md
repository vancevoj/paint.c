# paint.c

A native C17 raster image editor with the Paint.NET 5.1 workflow, for Linux
(Wayland and X11), Windows and macOS. Layers with the 14 classic blend modes,
selections and the magic wand, brushes with pen pressure, adjustments and
effects with live preview, branching undo, plugins, and PNG, JPEG, BMP, GIF,
TGA, TIFF, WebP, DDS, OpenRaster and .pdn files.

paint.c is an independent clean-room project. It is not affiliated with or
endorsed by dotPDN LLC; Paint.NET is their trademark. See NOTICE for the MIT
attribution of the Paint.NET 3.36 blend math.

## Plugins (optional downloads)

paint.c runs native effect plugins. The official ones below are separate
downloads from the
[plugins-v1.0.0 release](https://github.com/vancevoj/paint.c/releases/tag/plugins-v1.0.0):
unzip one into your plugins folder (Linux `~/.local/share/paintc/plugins`,
Windows `%APPDATA%\paintc\plugins`, macOS
`~/Library/Application Support/paint.c/plugins`) and restart paint.c. Each
one re-creates a popular Paint.NET plugin natively; the designs are the
work of the original authors credited in the table and in each plugin's
README.

Paint.NET's own plugins are .NET assemblies and cannot be loaded by
paint.c; only native plugins written for paint.c's C interface work.
Checksums are in `SHA256SUMS` on the release page. Installing, how plugins
work and writing your own: [docs/PLUGINS.md](docs/PLUGINS.md).

## Build and test

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build && ctest --test-dir build
./build/pc_tests            # full reference suite
```
