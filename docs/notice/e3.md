# Lane E3 attribution notes (shapes, line/curve, text engines)

No code was copied or translated from any Paint.NET release. The lane read
the MIT-licensed Paint.NET 3.36 source (mirror: github.com/rivy/OpenPDN,
Copyright dotPDN LLC, Rick Brewster, Tom Jackson and contributors, MIT, see
NOTICE) only for the behaviors and parameters listed here. Paint.NET 4.x and
5.x code was never used (P-01, ADR-002); 5.1 behavior comes from the official
documentation (names, options, modifier keys) as summarized in
docs/inventory/TOOLS.md.

| 3.36 file | What was taken | Where it is used |
|---|---|---|
| src/tools/ShapeTool.cs | Behavior: the outline is drawn with the drawing color (primary for the left button) and the interior with the other color; when only the interior is drawn the colors swap so the interior gets the drawing color. Pattern brushes use the two colors as foreground and background. | pc_shape_pick_colors |
| src/Core/Utility.cs (PointsToConstrainedRectangle) | Behavior: a Shift-constrained box takes the smaller of the dragged width and height and stays anchored at the press point. | pc_shape_from_drag (generalized to the shape's natural aspect) |
| src/tools/LineTool.cs | The 15 degree angle snapping rounds 12 * angle / pi to the nearest integer and keeps the length (ConstrainPoints); a new line gets its control points evenly spaced from start to end (LineToSpline); four control points; lines are positioned on pixel centers (PixelOffsetMode.None). | pc_linecurve_from_drag, snap_dir in pc_linecurve.c, pc_snap_stroke_coord |
| src/tools/RectangleTool.cs | Behavior: width 1 outlines are placed on pixel centers (PixelOffsetMode.None) so they stay crisp. | pc_snap_stroke_coord |
| src/tools/TextTool.cs | Behavior: the first text line is vertically centered on the click point (GetUpperLeft), following lines are stacked by the line height, Center and Right alignment shift each line by half or all of its width; Up on the first line and Down on the last line leave the caret where it is. | pc_text layout (PC_TEXT_ANCHOR_LINE_CENTER default), pc_text_move_caret |

Everything else is original work of this project: the geometry of all 29
shapes (designed from the shape names and the documentation's pictures, not
from Paint.NET's shape files), the editable shape model with rotation pivot
and handle hit-testing, the banded vector renderer with layer stacking and
pixelated selection clipping, the thin line rasterizer and dash splitter, the
cluster-aware text editor, the layout engine, the synthetic bold and italic,
and the glyph cache. The spline tension convention is L1a's (see
docs/notice/l1a.md).
