# Lane E1 attribution notes (brush engine, Pencil, Clone Stamp, Recolor)

No code was copied or translated from any Paint.NET release. Paint.NET
4.x, 5.x and 6.x were never decompiled or disassembled (P-01, ADR-002);
their behavior was taken from the official documentation mirror, the
release notes, public forum posts by the author, and black-box
observation of the running application (Paint.NET 5.2 under Wine,
ADR-009; see docs/core/brush.md, Measurements). The lane read the
MIT-licensed Paint.NET 3.36.7 source (mirror: github.com/rivy/OpenPDN,
Copyright dotPDN LLC, Rick Brewster, Tom Jackson and contributors, MIT,
see NOTICE) only for the algorithms and behaviors listed here.

| 3.36 file | What was taken | Where it is used |
|---|---|---|
| src/tools/RecoloringTool.cs (DrawOverPoints) | The recolor rule: a pixel within tolerance of the color being replaced gets every color channel shifted by (replacement - replaced), clamped to 0..255, and keeps its own alpha; at a partially covered (antialiased) brush pixel the adjusted color is blended over the pixel by the brush coverage and the alpha is restored. Paint.NET 5.2 was observed to produce exactly this shift. | pc_recolor_pixel, pc_recolor_row (the blend is done by pc_paint_apply in Overwrite mode, which keeps alpha when both pixels share it) |
| src/Core/Utility.cs (GetLinePoints) | The line rasterization: one point per step of the major axis, the error term increased before each point, the minor coordinate stepping when it reaches the major length, and a plain diagonal when both lengths are equal. Paint.NET 5.2's Pencil was observed to produce the same pixels. | pencil_line in src/core/pc_brush.c |
| src/tools/PencilTool.cs | Behavior: 1 px aliased lines between successive pointer positions, the start pixel of later segments not drawn again, primary or secondary color with its alpha. | PC_BRUSH_TIP_PENCIL |
| src/tools/CloneStampTool.cs | Behavior: when the source layer is the active layer, source pixels come from a copy of the layer saved before painting (no smearing); the take-from point moves with the stroke and persists between strokes until Ctrl+click sets a new one, which is a fixed offset. | pc_clone (pc_txn_original sampling, offset locked by the first stroke) |

Not taken: the 3.36 tolerance restriction of the Recolor tool (it only
prevented recoloring pixels twice while painting in place, which cannot
happen here because every result is computed from the stroke-start
pixels, and it would contradict the 5.1 documentation that 100%
tolerance recolors everything), the 3.36 ColorDifference metric (the
Recolor tolerance law was measured instead), and the 3.36 Paintbrush (a
filled polygon per mouse move with a squared pressure curve).

Other sources: the modified Bessel function I0 in the dab profile uses
the polynomial approximations 9.8.1 and 9.8.2 of Abramowitz and Stegun,
Handbook of Mathematical Functions (a US government publication in the
public domain). The dab profile parameters, the build-up accumulation,
the 1 px spacing floor, the centripetal Catmull-Rom smoothing with
reflected end points and the Recolor tolerance law are paint.c's own
models fitted to black-box observations; the Catmull-Rom evaluation is
the standard Barry-Goldman recursion.

Everything else is original work of this project: the arc-length dab
walker with carry, the sparse A8 stroke coverage with per-event change
tracking, the band grouping of changed tiles for pc_paint_apply, and the
lookup tables of the blurred-disk profile.
