# Lane I (integration, I/O, platform, packaging) attribution notes

The lane I code (src/app/main.c, fileio.c, settings.c, script.c,
mods/mod_file.c, io/, platform/, packaging/, tests/app/test_i_*.c) contains
no code copied, ported or transliterated from any Paint.NET release. The File
menu follows the Paint.NET 5.1 documentation as recorded in docs/inventory
(MENUS.md, FILES.md, OBSERVED.md); every longer text (dialog wording, error
messages, tooltips) is paint.c's own (ADR-013). Where the documentation is
silent, a few behaviors were derived from reading the MIT-licensed Paint.NET
3.36 source (OpenPDN mirror, "Paint.NET 3.36, Copyright (C) dotPDN LLC, Rick
Brewster, Tom Jackson, and contributors", MIT License; see NOTICE). Only the
behavior was taken; the implementations are original C.

| 3.36 file | What was derived | Where |
|---|---|---|
| src/DocumentWorkspace.cs (DoSaveAs) | Default Save As type: the current type unless the image has several layers and the type cannot keep them, then .pdn for layered images, else PNG; the default file name is the current one with the type's default extension. | src/app/fileio.c: default_save_codec, ask_path |
| src/Actions/CloseAllWorkspacesAction.cs, src/UnsavedChangesDialog.cs | Closing several images: with exactly one unsaved image the normal per-image prompt is used; with more, one dialog lists the unsaved images (clicking one shows it) and offers Save (each image in turn, stopping at the first cancel or failure), Don't Save and Cancel; after Cancel the image that was active before is shown again. | src/app/fileio.c: app_close_all, close_all_frame, app_quit_unsaved |
| src/MainForm.cs (OnDragDrop, PruneDirectories) | Dropped files: folders are ignored, then the user chooses Open (each file in its own image), add as layers (Import From File into the active image, a new image of the default size first when none is open) or Cancel. | src/app/io/drop.c: app_drop_files |
| src/Actions/ImportFromFileAction.cs | Importing a file as layers: a larger image grows the canvas (anchored top left) before its layers are added above the active layer, and the bounds of the last imported layer become the selection. The new canvas area is transparent and the layer names follow OBSERVED.md 4.2 ("<file>:<layer>"), both per MENUS.md. | src/app/io/drop.c: import_one, import_done |

Autosave and crash recovery, recent file thumbnails, the settings backups and
the packaging have no Paint.NET counterpart and are paint.c designs.

The application icon (assets/icons, generated by
packaging/icons/make_icons.py) is an original design: a white pixel dot and
a color-wheel letter c on a dark blue rounded tile. No Paint.NET icons,
images, resource strings or other assets are used (P-02, X-02).

Third-party license texts shipped with the packages are in
packaging/licenses (see its README.txt and docs/PACKAGING.md).
