# Lane E2 attribution notes (fill engines: patterns, gradients, wand and bucket)

No code was copied or translated from any Paint.NET release. The lane read
the MIT-licensed Paint.NET 3.36 source (mirror: github.com/rivy/OpenPDN,
Copyright dotPDN LLC, Rick Brewster, Tom Jackson and contributors, MIT,
see NOTICE) only for the behaviors and formulas listed here.

| 3.36 file | What was taken | Where it is used |
|---|---|---|
| src/Core/GradientRenderers.cs | The position parameter of the Linear (projection on start to end, divided by the squared length), Linear Reflected (absolute value of it), Linear Diamond (sum of the absolute projections on the axis and its normal) and Radial (distance divided by length) gradients, and the Conical rule (angle around the start relative to the start to end direction, divided by pi, folded to 0..1). | pc_gradient_u |
| src/Core/GradientRenderer.cs | Transparency mode: start alpha = primary alpha, end alpha = 255 - secondary alpha; with alpha blending the layer alpha is multiplied by the ramp alpha (rounded a * g / 255), without it the alpha is replaced; color channels are kept. Start equal to end fills with the end color or end alpha. | pc_gradient_colors, pc_gradient_apply (alpha path), degenerate gradients |
| src/tools/GradientTool.cs | Right mouse button: Color mode swaps the colors, Transparency mode reverses and inverts the alpha pair. Shift constrains the dragged point to multiples of 15 degrees around the other one, keeping the distance. Status angle = -atan2(dy, dx) in degrees. | pc_gradient_colors (reversed), pc_gradient_constrain, pc_gradient_measure |
| src/Core/ColorBgra.cs (Blend) | Color interpolation weights each color by its alpha (premultiplied interpolation), so fades to a transparent color keep the hue. | pc_gradient color ramp (own floating-point form) |
| src/tools/FloodToolBase.cs | Behavior only: the Paint Bucket ignores clicks outside the selection, the selection limits the flood, Shift toggles the flood mode; contiguous floods are 4-connected scanline floods. | pc_region_compute (limit_to_selection), pc_wand_opts.diagonal default |

Not taken from 3.36: its tolerance metric (CheckColor) and its tolerance
squaring, which Paint.NET 4 and later replaced. The tolerance metric of
pc_wand was measured black-box on Paint.NET (ADR-002, ADR-009) and is
described with the measurements in docs/core/fills.md.

Everything else is this project's own work: the 53 fill pattern bitmaps
(drawn for paint.c from the visual descriptions of the classic hatch
styles; the Percent screens are thresholds of the public-domain 8 x 8
Bayer ordered-dither matrix), the spiral gradients, repeat modes, seam
supersampling and the 16 x 16 Bayer dithering of gradients, the sparse
bit-tile regions and word-level scanline flood, the antialiased bucket
edge rule, and all transaction plumbing.
