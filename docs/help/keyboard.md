The tables on this page are generated from the key map of the paint.c you
are running, so they always match it. On macOS, Cmd takes the place of Ctrl
in menu shortcuts and Option the place of Alt.

Press a letter again within a second to reach the next tool with the same
letter; Shift + the letter goes the other way.

## Moving around

| Keys and mouse | Action |
|---|---|
| Space + drag, or middle button drag | Pan the view in any tool |
| Space + arrow keys | Pan by a few pixels ({{ctrl}}: ten times as far) |
| {{ctrl}} + mouse wheel | Zoom at the pointer |
| Mouse wheel, Shift + mouse wheel | Scroll up and down, left and right |
| Home, End (twice) | Scroll to the left or right edge (then to the corner) |
| Arrow keys | Move the pointer by one image pixel, {{ctrl}}: ten; faster while held |
| Enter, Esc | Finish the tool's editable object; with nothing to finish, deselect |

## Menus from the keyboard

- On Windows and Linux, press and release {{alt}} alone to move the keyboard
  to the menu bar: the arrow keys move between menus, Enter or Down opens
  one and the underlined letters choose items. Press {{alt}} again or Esc to
  leave.
- {{alt}} + an underlined letter opens a menu directly (for example {{alt}}+F
  for File). Inside a menu, the underlined letter chooses the item.
- {{alt}}+H opens the Help menu, {{alt}}+T the tool chooser and {{alt}}+X Settings;
  after a lone {{alt}}, H, T and X alone do the same.
- F10 opens the first menu.

## Text fields and dialogs

- Enter confirms a dialog, Esc cancels it.
- Tab and Shift+Tab move between fields.
- In number fields, the Up and Down arrow keys and the mouse wheel change
  the value.
